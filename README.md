# Little Star Snuggle

An original 768×768 illustration of a baby seal hugging a glowing star, created for make.fun's `cutest-picture-01` bounty. The submitted program copies the image to `/output/entry.png` using only the Node.js standard library.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The picture is original artwork; no external images or fonts are used.
